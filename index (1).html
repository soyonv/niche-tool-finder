Sort Lines

Sort any list A–Z, Z–A, by number, by length — or shuffle it.

one item per line
Options

Ready when you are.

Runs in your browser. Nothing you paste is uploaded, stored or logged — no account, no server, no limits.

How to use it

  1. Paste the list you want to order.
  2. Pick a sort mode: A→Z, Z→A, natural order, numeric, by length, reverse or shuffle.
  3. Choose whether blank lines should sink to the bottom of the result.
  4. Copy the sorted list when the order looks right.

Options explained

Sort mode
Alphabetical modes ignore case and accents. Natural order understands embedded numbers (line2 before line10). Numeric sorts by the first number found in each line. Length sorts shortest first. Shuffle uses a stable seed, so the same text always shuffles the same way.
Trim lines before sorting
Ignores leading and trailing spaces when ordering, so “ apple” does not sort before “banana” by accident.
Keep blank lines at the bottom
On by default: empty lines are gathered to the end instead of floating to the top of an A→Z sort.

Worked example

Input

pear
apple 10
banana
apple 2
cherry

Output

apple 2
apple 10
banana
cherry
pear

Frequently asked questions

Is my list uploaded to be sorted?

No. Sorting happens locally in JavaScript — no server, no account, no storage.

Why does item10 appear before item2 in a normal sort?

Plain alphabetical sorting treats numbers as text. Use the Natural (A→Z, numbers aware) mode and item2 will come first.

Is the shuffle really random?

It is seeded from your text, so the same input always produces the same order — which keeps results reproducible while you edit. Change the text and you get a new order.

Can it sort by a specific column (e.g. CSV)?

Not yet — this tool sorts whole lines. Column-aware sorting for pasted tables is on the roadmap for the CSV wave.
