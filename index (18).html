Frequently asked questions
Is ScrubKit really free?
Yes. Every tool is free with no signup, no usage caps and no “3 free runs per day” limit. The tools are small, static web pages that run on your device, so serving them costs almost nothing.
Do you see the text I paste?
No. Processing happens entirely inside your browser with local JavaScript. There is no upload endpoint, no account system and no database storing your content — see the privacy page for the full detail.
Is there a size limit?
No artificial limit. Small inputs are processed instantly; larger inputs (over about 100 KB) are handed to a background Web Worker so the page stays responsive while the work happens.
Does it work on a phone?
Yes. The tools are built mobile-first: big touch targets, textareas that work with the native keyboard, and outputs you can copy straight into other apps.
Which browsers are supported?
Current versions of Chrome, Edge, Firefox and Safari. Nothing needs to be installed and no browser extension is required.
