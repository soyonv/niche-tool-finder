Remove Invisible Characters

Find and delete hidden Unicode characters — zero-width, BOM, non-breaking and directional marks.

one item per line

Runs in your browser. Nothing you paste is uploaded, stored or logged — no account, no server, no limits.

How to use it

  1. Paste the text that refuses to match, copy or import correctly.
  2. Choose which groups to clean: zero-width characters, non-breaking spaces, directional formatting marks, soft hyphens.
  3. Read the result line: it lists each removed character name and its count, so you know what went wrong.
  4. Copy the cleaned text and retry your import, search or merge.

Options explained

Remove zero-width characters
Zero-width space, non-joiner, joiner, word joiner, BOM and combining grapheme joiner — characters that take up no space but break equality checks.
Replace non-breaking spaces with normal spaces
U+00A0 looks identical to a regular space but compares unequal. It is replaced with a standard space rather than deleted, so words do not fuse together.
Remove directional formatting characters
Hidden LTR/RTL overrides and isolates — including the characters used in “Trojan Source” style spoofing and reversed filenames.
Remove soft hyphens
U+00AD is an invisible hyphen inserted by word processors; it silently splits search terms.

Frequently asked questions

How do I know my text has invisible characters?

The result line names every character it removed with a count — for example “ZERO WIDTH SPACE ×9”. If the count is zero, your problem is elsewhere.

Why does my CSV import fail on one row?

A hidden character changes the string, so the row no longer matches your keys or schema. Paste the failing row here to see it named.

Are these the same as emoji or formatting?

No — this tool only targets invisible control and formatting characters. Visible emoji, letters and punctuation are untouched.

Does removing them change how my text displays?

Almost never. Zero-width characters are invisible by definition. The one visible exception is soft hyphenation, which currently only shows when a line breaks at that point.

Is my text uploaded for analysis?

No. Detection runs entirely in your browser with local JavaScript; no server sees your data.
