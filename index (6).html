Find and Replace

Replace text across a whole document — with optional regular expressions.

one item per line
Options

Ready when you are.

Runs in your browser. Nothing you paste is uploaded, stored or logged — no account, no server, no limits.

How to use it

  1. Paste the text you want to edit.
  2. Type what to find and what to replace it with.
  3. Enable regular-expression mode if your search pattern uses regex syntax; leave case-sensitive off unless capitalisation matters.
  4. Check the match count, then copy the result.

Options explained

Regular expression mode
Treats the Find field as a regex pattern, including groups and anchors. If the pattern is invalid the original text is returned unchanged and the error is shown in plain English.
Case-sensitive
When off (default), “cat” matches “Cat” and “CAT”.

Worked example

Input

alice@example.com, bob@example.com, carol@example.com

Output

alice@example.com
bob@example.com
carol@example.com

Frequently asked questions

Does this upload my document?

No — search and replacement run locally in your browser. Nothing is transmitted.

What regex flavour does it use?

Standard JavaScript regular expressions, the same syntax used everywhere in modern browsers, including lookbehind.

Can I replace across line breaks?

Yes with regex mode: type \n in the Find field to match newlines, and \n in the Replace field to insert them.

Why does nothing happen when my regex fails?

A broken pattern returns your original text plus a readable error in the status line instead of wiping or half-editing your input.

Is there a match limit?

No artificial limit. Very large inputs switch processing to a background Web Worker so the page keeps responding while replacements run.
