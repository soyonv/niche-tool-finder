Privacy

Nothing you paste leaves your browser.

This page is the boring, specific version of that promise.

What happens to your text

ScrubKit is a static website: HTML, CSS and JavaScript files served from a CDN. When you paste text into a tool, the transformation runs as JavaScript inside your browser tab. There is no upload request, no API call and no server-side processing — the code that cleans your text is the same code that draws the page.

When you close the tab, whatever you pasted is gone. We do not keep a copy because no copy was ever made outside your device.

What we store

Tool options (for example “case-sensitive comparison” or your preferred slug separator) are saved in your browser's localStorage so the tool behaves the way you left it on your next visit. That preference storage lives on your device and can be cleared at any time from your browser settings. Your pasted text is never written to localStorage, cookies, IndexedDB or anywhere else.

Cookies and tracking

There are no cookies. There are no analytics scripts, no session recorders, no advertising networks and no third-party requests on tool pages. If you open your browser's network panel while using a tool, you'll see the page load and nothing else.

Accounts

There are none. No signup, no login, no email collection, no password database — because there is no backend to hold one.

Hosting and server logs

The site's files are served by our static host, which keeps standard technical access logs (IP address, user agent, requested path, time) for security and abuse prevention, as almost every web host does. Those logs contain the URLs requested — never the content of your pasted text, which is never transmitted in the first place.

Changes to this policy

If any part of this ever changes — for example, if a future feature genuinely needs a server — it will be stated here in plain language before that feature exists, and it will be opt-in. The core promise (“nothing you paste is uploaded”) is the product; it is not for sale.
